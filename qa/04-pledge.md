# 04. 다짐

## 1. 도메인 정의

회원이 본인의 목표나 약속(다짐)을 작성·공개하고, 다른 회원이 좋아요·북마크·댓글로 응원할 수 있게 하는 도메인. 본인의 다짐 이력은 마이페이지에서도 확인할 수 있다.

## 2. 핵심 개념·용어

- **다짐**: 회원이 자신에게 또는 공개적으로 선언하는 목표·약속.
- **반응**: 다짐에 표하는 좋아요·북마크.
- **댓글**: 다짐에 응원·의견을 남기는 짧은 글.

## 3. 기능 요구사항

### 3.1 다짐 둘러보기·읽기

#### 다짐 둘러보기

> 회원이 다른 회원의 다짐을 둘러보며 영감을 얻을 수 있다.

**누가**: 정상 회원

**정상 흐름**: 페이지 단위 목록 + 새로고침.

**정책**: 차단한 사용자가 작성한 다짐 노출 제외.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 다짐 0개 | 빈 결과 안내 |

#### 다짐 자세히 보기

> 회원이 특정 다짐의 본문과 응원 댓글을 확인할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 본문 + 댓글이 페이지 단위로 표시됨.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 이미 삭제된 다짐 | 안내 후 뒤로가기 |
| 차단한 작성자의 다짐 | 진입 차단 또는 안내 |

### 3.2 다짐 작성·관리

#### 다짐 작성

> 회원이 본인의 목표를 다짐으로 작성·공개할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 제목·내용·(목표 기간 등) 입력 → 등록.

**입력 조건**

| 항목 | 조건 |
|------|------|
| 제목·내용 | 길이 제한 내, 빈 내용 차단 |
| 부적절한 단어 | 차단 |

#### 다짐 수정

> 작성자가 본인의 다짐을 수정할 수 있다.

**누가**: 본인

**정상 흐름**: 본인 다짐 수정 → 저장.

#### 다짐 삭제

> 작성자가 본인의 다짐을 삭제할 수 있다.

**누가**: 본인

**정상 흐름**: 삭제 확인 → 모든 화면(피드/내 다짐)에서 즉시 사라짐.

### 3.3 반응·댓글

#### 다짐 좋아요·북마크

> 회원이 인상 깊은 다짐에 응원이나 저장 표시를 할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 하트/북마크 토글.

#### 다짐 댓글

> 회원이 다짐에 응원 메시지나 의견을 남길 수 있다.

**누가**: 정상 회원

**정상 흐름**: 댓글 작성 / 삭제 / 좋아요.

**정책**: 글자수, 부적절한 단어, 차단 정책은 커뮤니티 댓글과 동일.

### 3.4 내 다짐 이력

#### 내 다짐 이력 조회

> 회원이 본인이 작성한 다짐을 모아 볼 수 있다.

**누가**: 본인

**정상 흐름**: 본인 작성 다짐을 페이지 단위로 조회.

## 4. 알림 발송 명세

| 트리거 | 수신자 | 본문 (예시) | 카테고리 |
|--------|--------|-----------|---------|
| 내 다짐에 좋아요 | 다짐 작성자 | "{닉네임}님이 회원님의 다짐을 응원합니다." | 좋아요 |
| 내 다짐에 새 댓글 | 다짐 작성자 | "{닉네임}님이 응원 댓글을 남겼습니다: {댓글 일부}" | 댓글 |

**공통 정책**: 차단 관계인 사용자에게는 알림 발송 제외. 빠른 연속 좋아요는 배치 발송.

## 5. 정책·규칙

| 항목 | 값 |
|------|------|
| 차단 영향 | 커뮤니티와 동일 |
| 부적절 단어 차단 | 작성·수정 시 동일 적용 |

## 6. 도메인 공통 예외

- 좋아요·북마크 토글의 빠른 연타 시 마지막 상태가 정확해야 함.
