# 08. 마이페이지·설정

## 1. 도메인 정의

회원 본인의 활동 이력을 모아 보고, 알림·고객지원 등 부가 설정을 관리하는 도메인. 회원 정보 자체의 변경(프로필·비밀번호·탈퇴 등)은 **회원 도메인**에서 다룬다.

> 본 문서와 회원 도메인의 분담:
> - **회원 도메인**: 가입·로그인·프로필 수정·비밀번호 변경·로그아웃·탈퇴.
> - **마이페이지**: 내 활동 이력·알림 설정·정책 페이지 진입·고객지원.

## 2. 기능 요구사항

### 2.1 활동 이력 조회

#### 마이페이지 요약 보기

> 회원이 본인의 닉네임·학교·전공·배지·활동 점수 등 핵심 정보를 한 화면에서 확인할 수 있다.

**누가**: 본인

**정상 흐름**: 진입 시 본인 프로필 요약 + 각 항목별 진입 메뉴 표시.

**정책**: 학생증 미인증 회원에게는 일부 항목이 비활성/숨김.

#### 내가 쓴 글·댓글 조회

> 회원이 본인이 작성한 게시글·댓글을 모아 볼 수 있다.

**누가**: 본인

**정상 흐름**: 내 게시글 / 내 댓글을 각각 페이지 단위로 조회.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 작성한 글이 삭제됨 | 목록에서 자동 제거 |

#### 좋아요한 글·북마크한 글 조회

> 회원이 본인이 좋아요/북마크한 글을 다시 찾아볼 수 있다.

**누가**: 본인

**정상 흐름**: 좋아요 / 북마크 목록을 각각 페이지 단위로 조회. 다짐·투표 등 다른 콘텐츠 유형까지 통합 조회는 검색·알림 도메인의 "내 활동 통합 조회" 참조.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 원본 콘텐츠가 삭제됨 | 자동으로 목록에서 제외 |

### 2.2 알림 설정

#### 알림 카테고리별 수신 설정

> 회원이 어떤 종류의 알림을 받을지 카테고리별로 직접 결정할 수 있다.

**누가**: 본인

**정상 흐름**: 카테고리별 토글(좋아요/댓글/팔로우/공지 등) 변경 → 즉시 저장.

**정책**

- OS 알림 권한이 거부된 상태에서 토글 ON 시도 시 OS 설정으로 이동 안내
- 마케팅 미동의 회원에게는 마케팅성 알림이 일체 발송되지 않음
- 시스템·보안·신고 카테고리는 끌 수 없음(공통 정책의 알림 카테고리 정의 참조)

### 2.3 정책·고객지원

#### 차단·약관 이력 진입

> 회원이 본인이 차단한 사용자 목록과 약관 동의 이력 등 보안 관련 항목에 한 곳에서 진입할 수 있다.

**누가**: 본인

**정상 흐름**: 메뉴에서 각 항목 진입.

**연결 기능**

| 메뉴 | 연결 |
|------|------|
| 차단한 사용자 목록 | 신고·차단 도메인 |
| 약관 동의 이력 | 회원 도메인 |
| 비밀번호 변경 | 회원 도메인 |
| 회원 탈퇴 | 회원 도메인 |

#### 고객지원 진입

> 회원이 사용 중 문제가 있을 때 안내·문의 채널에 접근할 수 있다.

**누가**: 정상 회원

**정상 흐름**: FAQ, 1:1 문의(메일 또는 외부 폼), 정책 안내 진입.

**정책**: 외부 링크는 외부 브라우저로 열린다.

#### 앱 정보·정책 페이지 진입

> 회원이 현재 앱 버전과 이용약관·개인정보 처리방침 등을 확인할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 현재 앱 버전 표시. 다음 외부 링크로 이동.

**연결 링크**

| 항목 | 링크 |
|------|------|
| 이용약관 | `https://www.claspeek.com/terms/` |
| 개인정보 처리방침 | `https://www.claspeek.com/privacy/` |
| 고객지원 | `https://www.claspeek.com/support/` |
| 계정 삭제 안내 | `https://www.claspeek.com/account-deletion/` |

**예외 처리**

| 상황 | 결과 |
|------|------|
| 인터넷 연결 없음 | 외부 링크 진입 실패 안내 |

## 3. 정책·규칙

| 항목 | 값 |
|------|-----|
| 활동 카운트 일관성 | 마이페이지의 모든 카운트가 다른 화면의 동일 카운트와 일치 |
| 삭제·차단 즉시 반영 | 본인 글 삭제·차단 사용자 정리 직후 마이페이지의 목록·카운트가 즉시 갱신 |
| 회원 정보 변경 진입점 | 프로필·비밀번호·탈퇴 등은 본 도메인이 아닌 회원 도메인의 기능 호출 진입점만 제공 |

## 4. 도메인 공통 예외

- 프로필 이미지 변경 후 다른 화면(피드 작성자 아바타 등)에 캐시된 이전 이미지가 남아 있지 않은지.
