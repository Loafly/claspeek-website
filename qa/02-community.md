# 02. 커뮤니티

## 1. 도메인 정의

회원이 글을 작성·공유하고, 다른 회원과 댓글·좋아요·북마크로 소통하는 도메인. 게시글은 학교 단위 또는 전체 단위로 노출되어 학생 간 정보·이야기 교류를 가능하게 한다.

## 2. 핵심 개념·용어

- **게시글**: 회원이 작성한 콘텐츠(제목·본문·이미지). 작성자만 수정·삭제 가능.
- **댓글**: 게시글에 달리는 짧은 글. 대댓글 지원 여부는 운영 정책으로 정의.
- **좋아요**: 회원이 게시글·댓글에 표하는 공감. 토글 방식.
- **북마크(저장)**: 회원이 다시 보고 싶은 게시글을 본인 컬렉션에 보관. 본인만 조회.
- **학교 채널**: 동일 학교 회원들의 게시글이 모이는 공간.
- **인기**: 좋아요·댓글 수 등 활동량을 기준으로 일정 기간 동안 노출 우선순위가 높아지는 게시글.

## 3. 기능 요구사항

### 3.1 글 둘러보기·읽기

#### 게시글 둘러보기

> 회원이 새로운/인기 있는 게시글을 발견할 수 있다.

**누가**: 정상 회원

**정상 흐름**
1. 진입 시 첫 페이지의 게시글이 자동 로드
2. 아래로 스크롤하면 다음 페이지가 이어서 로드
3. 위로 당겨 새로고침
4. 정렬·필터(최신/인기/카테고리/학교 채널 등) 선택 시 즉시 반영

**정책**

- 차단한 사용자의 게시글은 결과에서 제외
- 신고 누적으로 자동 숨김된 게시글은 결과에서 제외

**예외 처리**

| 상황 | 결과 |
|------|------|
| 게시글이 0개 | 빈 화면 안내 |
| 페이지 끝 도달 후 추가 로드 시도 | 같은 글이 중복 로드되지 않음 |

#### 게시글 자세히 보기

> 회원이 관심 있는 게시글의 본문과 댓글을 모두 확인할 수 있다.

**누가**: 정상 회원

**정상 흐름**
1. 게시글 본문·작성자·작성 시각·반응 수가 표시됨
2. 댓글이 페이지 단위로 표시됨
3. 좋아요·북마크·공유·신고 액션이 노출됨

**예외 처리**

| 상황 | 결과 |
|------|------|
| 이미 삭제된 게시글 | 안내 후 뒤로가기 |
| 차단한 작성자의 글 | 진입 차단 또는 안내 |

### 3.2 글 작성·관리

#### 게시글 작성

> 회원이 본인의 생각·정보·질문을 글로 작성하여 다른 회원과 공유할 수 있다.

**누가**: 정상 회원

**정상 흐름**
1. 제목·본문·카테고리·이미지(선택) 입력
2. "등록" 버튼 탭
3. 성공 시 상세 화면 이동 또는 피드 새로고침

**입력 조건**

| 항목 | 조건 |
|------|------|
| 제목 | 글자수 상한 내(운영 정책) |
| 본문 | 글자수 상한 내, 빈 본문 차단 |
| 부적절한 단어 | 차단 |
| 이미지(선택) | 공통 정책의 이미지 업로드 동작 따름 |

**예외 처리**

| 상황 | 결과 |
|------|------|
| 빈 본문 등록 시도 | 등록 차단 |
| 부적절한 단어 포함 | 차단 메시지 |
| 작성 중 세션 만료 | 자동 갱신 후 재시도, 사용자가 인지하지 못해야 함 |
| 작성 도중 백그라운드 진입 후 복귀 | 임시 저장 동작 여부는 운영 정책으로 정의 |

#### 게시글 수정

> 작성자가 본인의 게시글을 수정하여 오타나 잘못된 내용을 바로잡을 수 있다.

**누가**: 본인

**정상 흐름**: 본인 글 → 더보기 → 수정 → 저장 → 상세 갱신.

**입력 조건**: 작성과 동일 정책.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 타인 글 수정 시도 | 거절 메시지 |
| 수정 가능 시간 초과 | 운영 정책에 따라 안내 |

#### 게시글 삭제

> 작성자가 본인의 게시글을 삭제할 수 있다.

**누가**: 본인

**정상 흐름**: 삭제 확인 → 모든 사용자 시점 화면(피드·검색·상세 등)에서 즉시 사라짐.

**정책**: 댓글이 달린 글의 삭제 정책(즉시 삭제 / 댓글 보존)은 운영 정책으로 정의.

### 3.3 반응

#### 게시글 좋아요

> 회원이 마음에 드는 게시글에 공감을 표할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 하트 탭 → 카운트 즉시 반영. 다시 탭하면 취소.

**정책**

- 본인 글에 좋아요 가능 여부는 운영 정책으로 정의
- 차단당한 상대방의 글에는 좋아요가 거절됨

**예외 처리**

| 상황 | 결과 |
|------|------|
| 빠른 연타 | 마지막 상태가 정확히 반영되어야 함 |

#### 게시글 북마크(저장)

> 회원이 다시 읽고 싶은 게시글을 본인 컬렉션에 저장할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 북마크 아이콘 탭 → 본인의 "저장한 글" 목록에 즉시 추가/제거.

### 3.4 댓글

#### 댓글 작성

> 회원이 게시글에 대한 의견을 댓글로 남길 수 있다.

**누가**: 정상 회원

**정상 흐름**: 텍스트 입력 → 전송 → 댓글 목록에 즉시 추가, 키보드 닫힘 + 입력창 초기화.

**입력 조건**

| 항목 | 조건 |
|------|------|
| 댓글 본문 | 글자수 상한 내, 빈 내용 차단 |
| 부적절한 단어 | 차단 |

**예외 처리**

| 상황 | 결과 |
|------|------|
| 작성자가 차단한 사용자의 댓글 시도 | 거절 |

#### 댓글 수정

> 작성자가 본인의 댓글을 수정할 수 있다.

**누가**: 본인

**정상 흐름**: 본인 댓글 길게 누름/메뉴 → 수정 → 저장.

#### 댓글 삭제

> 작성자가 본인의 댓글을 삭제할 수 있다.

**누가**: 본인

**정상 흐름**: 삭제 확인 → 즉시 목록에서 제거.

**정책**: 자식 댓글이 있는 댓글의 삭제 표시 정책(예: "삭제된 댓글입니다")은 운영 정책으로 정의.

#### 댓글 좋아요

> 회원이 좋은 댓글에 공감을 표할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 댓글의 하트 탭 → 카운트 반영.

## 4. 알림 발송 명세

| 트리거 | 수신자 | 본문 (예시) | 카테고리 |
|--------|--------|-----------|---------|
| 내 게시글에 좋아요 | 게시글 작성자 | "{닉네임}님이 회원님의 게시글을 좋아합니다." | 좋아요 |
| 내 게시글에 새 댓글 | 게시글 작성자 | "{닉네임}님이 댓글을 남겼습니다: {댓글 일부}" | 댓글 |
| 내 댓글에 답글(대댓글) | 부모 댓글 작성자 | "{닉네임}님이 답글을 남겼습니다." | 댓글 |
| 내 댓글에 좋아요 | 댓글 작성자 | "{닉네임}님이 회원님의 댓글을 좋아합니다." | 좋아요 |
| 운영 공지(전체 또는 학교별) | 전체 회원 또는 해당 학교 회원 | "{공지 제목}" | 공지 |

**공통 정책**
- 본인이 본인 글에 누른 좋아요·댓글은 알림 발송 대상 제외.
- 차단 관계 사이에서는 알림 발송 제외.
- 짧은 시간에 동일 트리거가 여러 번 발생하면 묶음(batch) 발송 — 운영 정책으로 정의.

## 5. 정책·규칙

| 항목 | 값 |
|------|------|
| 글자수 상한 | 제목·본문·댓글 모두 운영 정책으로 정의 |
| 부적절한 단어 차단 | 작성·수정 시 동일 적용 |
| 차단 영향 | 차단한·차단당한 사용자 콘텐츠는 모든 화면에서 노출 제외 |
| 신고 누적 자동 숨김 | 운영 정책으로 정의 |
| 이미지 첨부 | 운영 정책으로 첨부 가능 여부·개수·용량 정의 |

## 6. 도메인 공통 예외

- 작성·수정 중 인터넷 단절 → 재연결 시 자동 재시도 또는 명시적 재시도.
- 무한 스크롤 + 좋아요 토글의 동시 동작 시 스크롤 점프나 카운트 어긋남이 없어야 함.
- 본문에 HTML 태그·이모지·긴 URL 등 입력 시 표시 깨짐 없어야 함.
