# 03. 투표

## 1. 도메인 정의

회원이 다른 회원의 의견을 묻기 위해 투표를 만들고, 다른 회원들이 옵션을 선택하여 참여하는 도메인. 결과는 실시간으로 집계되고 댓글로 토론할 수 있다.

## 2. 핵심 개념·용어

- **투표**: 제목과 옵션(2개 이상)으로 구성되어 회원의 선택을 모으는 콘텐츠. 마감 일시를 설정할 수 있다.
- **옵션**: 투표에 포함된 선택지. 단일선택 또는 복수선택 모드 중 하나로 동작.
- **참여**: 회원이 옵션을 선택하여 의사를 표시하는 행동.
- **마감**: 투표가 더 이상 참여를 받지 않는 상태. 마감 후 결과는 보존된다.

## 3. 기능 요구사항

### 3.1 투표 둘러보기·읽기

#### 투표 둘러보기

> 회원이 진행 중·마감된 투표를 한눈에 볼 수 있다.

**누가**: 정상 회원

**정상 흐름**: 페이지 단위 목록 + 새로고침. 정렬·필터(진행 중/마감/인기 등) 옵션이 있다면 즉시 반영.

**정책**: 차단한 사용자가 만든 투표는 결과에서 제외.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 투표 0개 | 빈 결과 안내 |

#### 투표 자세히 보기

> 회원이 옵션 구성과 현재 집계 결과를 확인할 수 있다.

**누가**: 정상 회원

**정상 흐름**
1. 옵션·내 참여 여부·집계가 표시됨
2. 진행 중 / 마감 상태가 명확히 구분됨
3. 댓글이 페이지 단위로 조회됨

**정책**: 결과 비공개 정책(예: 마감 후에만 공개)이 있다면 운영 정책으로 정의하여 표시 분기.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 마감된 투표 | 옵션 변경/참여 불가 |
| 작성자 본인 참여 | 가능 여부 운영 정책으로 정의 |

### 3.2 투표 만들기·관리

#### 투표 만들기

> 회원이 다른 회원의 의견을 묻기 위해 투표를 직접 만들 수 있다.

**누가**: 정상 회원

**정상 흐름**: 제목 + 옵션 2개 이상 + 마감 일시(선택) + 단일/복수 선택 모드 입력 → 등록.

**입력 조건**

| 항목 | 조건 |
|------|------|
| 제목 | 글자수 상한 내, 부적절한 단어 차단 |
| 옵션 개수 | 최소 2개, 최대 N개(운영 정책) |
| 옵션 텍스트 | 빈 값·중복 차단 |
| 마감 일시 | 미래 시각만 허용(선택 사항) |

**예외 처리**

| 상황 | 결과 |
|------|------|
| 옵션 1개만 입력 | 등록 차단 |
| 마감 일시를 과거로 입력 | 등록 차단 |

#### 투표 삭제

> 작성자가 본인의 투표를 삭제할 수 있다.

**누가**: 본인

**정상 흐름**: 삭제 확인 → 즉시 목록에서 사라짐.

**정책**: 참여자가 있는 투표의 삭제 가능 여부는 운영 정책으로 정의.

### 3.3 투표 참여

#### 투표 참여

> 회원이 본인의 의견을 옵션 선택으로 표할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 옵션 선택 → 집계 즉시 반영.

**입력 조건**

| 항목 | 조건 |
|------|------|
| 단일선택 모드 | 옵션 1개만 선택 |
| 복수선택 모드 | 운영 정책에 정의된 최대 개수까지 선택 |

**정책**

- 마감 후 참여 시도는 거절
- 이미 참여한 회원의 재참여(변경 가능 / 불가능)는 운영 정책으로 정의
- 작성자 본인의 참여 가능 여부는 운영 정책으로 정의

**예외 처리**

| 상황 | 결과 |
|------|------|
| 마감 후 참여 시도 | 실패 메시지 |
| 차단당한 사용자의 참여 | 거절 |

### 3.4 반응·댓글

#### 투표 좋아요 / 북마크

> 회원이 인상 깊은 투표에 공감하거나 본인 컬렉션에 저장할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 하트/북마크 토글 → 즉시 반영.

#### 투표 댓글

> 회원이 투표 결과나 옵션에 대해 토론할 수 있다.

**누가**: 정상 회원

**정상 흐름**: 댓글 작성 / 삭제 / 좋아요 동작은 커뮤니티 댓글과 동일.

**정책**: 글자수, 부적절한 단어, 차단된 사용자 정책은 커뮤니티 댓글과 동일.

## 4. 알림 발송 명세

| 트리거 | 수신자 | 본문 (예시) | 카테고리 |
|--------|--------|-----------|---------|
| 내 투표에 새 참여자 | 투표 작성자 | "{N}명이 회원님의 투표에 참여했습니다." (배치 발송) | 활동 |
| 내 투표 마감 도래 | 투표 작성자 | "회원님의 투표가 마감되었습니다. 결과를 확인하세요." | 활동 |
| 내 투표에 새 댓글 | 투표 작성자 | "{닉네임}님이 댓글을 남겼습니다: {댓글 일부}" | 댓글 |
| 내 투표에 좋아요 | 투표 작성자 | "{닉네임}님이 회원님의 투표를 좋아합니다." | 좋아요 |

**공통 정책**
- 본인이 본인 투표에 한 행동은 알림 발송 대상 제외.
- 짧은 시간 안에 다수 참여자가 발생하면 배치 발송(예: 5~10분 단위 묶음).
- 차단 관계인 사용자에게는 알림 발송 제외.

## 5. 정책·규칙

| 항목 | 값 |
|------|------|
| 마감 시각 기준 | **서버 시각** 기준. 디바이스 시간을 임의로 바꿔도 우회 불가 |
| 옵션 추가/수정 | 등록 후 옵션 변경 불가(운영 정책으로 확정) |
| 결과 공개 시점 | 진행 중 공개 / 마감 후 공개 / 비공개 (운영 정책으로 정의) |

## 6. 도메인 공통 예외

- 마감 시각 직전·직후의 참여 시도는 서버 시각 기준으로 일관되게 처리.
- 동시에 여러 회원이 같은 투표에 참여 시 집계 합산이 정확해야 함.
