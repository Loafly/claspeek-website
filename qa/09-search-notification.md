# 09. 검색·알림

## 1. 도메인 정의

회원이 콘텐츠를 빠르게 찾고(검색), 관심 있는 활동의 소식을 받을 수 있게 하는(알림) 도메인. 검색은 게시글·다짐·투표 등 여러 콘텐츠를 가로지르는 통합 기능이며, 알림은 인앱 목록과 푸시 두 채널을 통해 전달된다.

## 2. 핵심 개념·용어

- **통합 검색**: 키워드 하나로 게시글·다짐·투표 등 여러 콘텐츠를 한 번에 찾는 기능.
- **알림**: 회원에게 발송되는 활동 소식(좋아요·댓글·공지·신고 처리 결과 등).
- **읽음 표시**: 회원이 알림을 확인했음을 시스템이 인지하는 상태 변화.
- **푸시 알림**: OS 알림 영역으로 발송되는 알림.

## 3. 기능 요구사항

### 3.1 검색

#### 통합 검색

> 회원이 키워드로 여러 콘텐츠를 한 번에 찾을 수 있다.

**누가**: 정상 회원

**정상 흐름**
1. 키워드 입력 → 짧은 대기 시간 후 결과 자동 표시(타이핑이 멈추면 검색)
2. 결과는 콘텐츠 유형별 그룹(게시글·다짐·투표·사용자 등)으로 표시
3. 결과 항목 클릭 시 해당 콘텐츠 상세로 이동

**입력 조건**

| 항목 | 조건 |
|------|------|
| 키워드 | 최소 글자수, 최대 글자수 운영 정책으로 정의 |

**정책**: 차단한 사용자가 작성한 결과 제외.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 결과 없음 | 빈 결과 안내 |
| 빠르게 입력 변경 | 마지막 키워드의 결과만 표시(이전 응답으로 덮이지 않음) |

#### 내 활동 통합 조회

> 회원이 본인의 활동(좋아요·북마크·내 글·내 댓글)을 콘텐츠 유형 가리지 않고 한 곳에서 볼 수 있다.

**누가**: 본인

**정상 흐름**: 좋아요 / 북마크 / 내 글 / 내 댓글 각각을 통합으로 페이지 단위 조회.

### 3.2 알림 조회·관리

#### 알림 목록 조회

> 회원이 본인에게 도착한 알림을 시간순으로 모아 볼 수 있다.

**누가**: 본인

**정상 흐름**
1. 알림 목록을 페이지 단위로 조회
2. 알림 클릭 시 연결된 콘텐츠 화면으로 이동
3. 클릭한 알림은 읽음으로 표시되고 읽지 않음 배지에서 제외

**예외 처리**

| 상황 | 결과 |
|------|------|
| 연결 콘텐츠가 이미 삭제됨 | 안내 후 목록 복귀 |

#### 알림 전체 읽음 처리

> 회원이 한 번에 모든 알림을 읽음 처리할 수 있다.

**누가**: 본인

**정상 흐름**: "모두 읽음" → 모든 알림이 즉시 읽음으로 표시.

**예외 처리**

| 상황 | 결과 |
|------|------|
| 처리 실패 | 안내 또는 자동 재시도 |

#### 알림 삭제

> 회원이 더 이상 보고 싶지 않은 알림을 개별 삭제할 수 있다.

**누가**: 본인

**정상 흐름**: 항목 스와이프 또는 메뉴에서 삭제 → 즉시 목록에서 사라짐.

### 3.3 푸시 알림 수신

#### 푸시 알림 수신 및 클릭 이동

> 회원이 앱을 켜지 않고도 본인에게 도달한 활동 소식을 받을 수 있고, 알림을 클릭하면 정확히 해당 콘텐츠로 이동해야 한다.

**누가**: 본인 (OS 알림 권한 허용 상태)

**정상 흐름**
1. 운영자 또는 시스템이 알림 발송
2. 디바이스에 알림 도착
3. 알림 탭 → 앱 실행/포그라운드 전환 + 해당 콘텐츠 화면으로 이동

**정책**

- 권한 거부 회원에게는 일체의 푸시가 도달하지 않아야 함
- 다중 디바이스 정책: 같은 계정을 두 기기에서 로그인 시 두 기기 모두 수신 여부는 운영 정책으로 정의
- 디바이스 변경/재설치 후 이전 디바이스로 발송된 알림이 도달하지 않아야 함

**예외 처리**

| 상황 | 결과 |
|------|------|
| 앱이 종료된 상태에서 알림 탭(콜드 스타트) | 앱 시작 후 정확히 해당 콘텐츠로 이동 |
| 클릭 시 세션 만료된 경우 | 자연스럽게 로그인 화면으로 안내 |

## 4. 알림 발송 명세

본 도메인은 알림을 받는 영역으로, 알림 트리거 자체는 다른 도메인에서 발생한다(회원·커뮤니티·투표·다짐·일정·다이어리·활동·신고 도메인의 "알림 발송 명세" 참조).

> 알림 카테고리 정의와 사용자 ON/OFF 정책은 공통 정책 문서의 "알림 카테고리 정의" 참조.

## 5. 정책·규칙

| 항목 | 값 |
|------|-----|
| 읽지 않음 배지 일관성 | 알림 카운트와 목록의 미읽음 항목 수가 항상 일치 |
| 검색 결과 제외 정책 | 차단된 사용자·삭제된 콘텐츠는 모든 검색 결과에서 제외 |
| 알림 카테고리 매핑 | 마이페이지의 알림 설정 변경이 즉시 반영 |

## 6. 도메인 공통 예외

- 알림 카드의 시간 표기(상대 시간 vs 절대 시간) 일관성과 시간대 처리.
- 푸시를 클릭해서 진입 시 세션 만료된 경우 매끄럽게 로그인으로 유도.
