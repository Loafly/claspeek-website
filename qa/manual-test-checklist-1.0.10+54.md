# 1.0.10+59 제출 전 통합 수동 검증 체크리스트

> **1.0.10+48 거부** 이후 +51 ~ +59 빌드에 누적된 **19가지 강화 + 부가 기능 다수**를 한 번에 검증.
> 이번 라운드 핵심: **연령 등급 16+ 로 조정** + **작성자 식별 정보 노출 강화** (nicknameWithCode, AuthorProviderBadge).
> 한 디바이스에서 위에서 아래로 순서대로 따라가면 모든 항목이 자동으로 검증되도록 구성됨.
> **iPhone → iPad → Android** 세 번 반복 (또는 시간 부족 시 iPhone + iPad 두 번).
