# 10. 신고·차단

## 1. 도메인 정의

부적절한 콘텐츠나 사용자로부터 회원을 보호하기 위한 도메인. 회원은 다른 사용자를 직접 **차단**하여 즉시 노출을 끊을 수 있고, 운영자에게 **신고**하여 사후 조치를 요청할 수 있다.

## 2. 핵심 개념·용어

- **차단(block)**: 회원이 다른 회원의 콘텐츠와 상호작용을 본인 계정에서 즉시 끊는 행동. 차단 즉시 효과 발생.
- **신고(report)**: 회원이 부적절한 콘텐츠/사용자를 운영자에게 알려 검토를 요청하는 행동. 운영자 검토 후 조치된다.
- **상호 차단**: 두 사용자가 서로 차단하고 있는 상태.
- **신고 누적 자동 숨김**: 동일 콘텐츠에 대한 신고가 일정 횟수 이상 누적되면 자동으로 다른 회원에게 노출되지 않도록 처리.

## 3. 기능 요구사항

### 3.1 차단

#### 사용자 차단

> 회원이 보고 싶지 않은 다른 사용자의 콘텐츠와 상호작용을 즉시 끊을 수 있다.

**누가**: 정상 회원

**정상 흐름**
1. 게시글·댓글·다짐·투표·프로필 등 어디에서나 더보기 → "사용자 차단"
2. 차단 확인
3. 즉시 효과: 차단된 사용자의 게시글·댓글·다짐·투표·검색 결과·알림 등 모든 노출 중단, 상호 작용 차단

**정책**

- 본인을 차단할 수 없음
- 이미 차단한 사용자에 대한 재차단은 부작용 없이 처리(중복 효과 없음)
- 상호 차단 상태에서도 노출/거절 동작이 일관되어야 함

**예외 처리**

| 상황 | 결과 |
|------|------|
| 차단 직후 캐시된 피드 화면 | 즉시 또는 새로고침으로 갱신 |
| 본인 차단 시도 | 차단 불가, 메시지 노출 |

#### 사용자 차단 해제

> 회원이 차단했던 사용자를 해제하여 다시 콘텐츠를 볼 수 있게 한다.

**누가**: 본인

**정상 흐름**: 차단 목록에서 "차단 해제" → 즉시 목록 제거. 이후 해당 사용자의 새 콘텐츠가 정상 노출.

**정책**: 차단 기간 동안 작성된 과거 콘텐츠 노출 정책(다시 보임 / 영구 숨김)을 운영 정책으로 정의.

#### 차단한 사용자 목록 조회

> 회원이 본인이 차단한 사용자를 모아 보고 관리할 수 있다.

**누가**: 본인

**정상 흐름**: 차단한 사용자 카드와 해제 버튼이 페이지 단위로 표시.

**정책**: 차단 대상 사용자가 탈퇴/영구 차단된 경우의 표시 처리 운영 정책으로 정의.

### 3.2 신고

#### 콘텐츠·사용자 신고

> 회원이 부적절한 콘텐츠나 사용자를 운영자에게 신고하여 안전한 환경 조성에 기여할 수 있다.

**누가**: 정상 회원

**정상 흐름**
1. 게시글·댓글·다짐·투표·프로필에서 더보기 → "신고"
2. 신고 대상 유형(게시글/댓글/사용자 등)이 자동 설정됨
3. 신고 사유 선택(필수) + 추가 설명(선택)
4. 접수 완료 안내

**입력 조건**

| 항목 | 조건 |
|------|------|
| 사유 | 미리 정의된 사유 중 1개 이상 선택 (필수) |
| 추가 설명 | 선택 입력, 글자수 제한 |

**정책**

- 본인 콘텐츠 신고 차단
- 동일 콘텐츠 중복 신고 정책(허용 / 차단)을 운영 정책으로 정의
- 신고 처리 결과는 운영자가 처리한 후 회원에게 알림으로 통지

**예외 처리**

| 상황 | 결과 |
|------|------|
| 본인 콘텐츠 신고 시도 | 신고 불가, 메시지 노출 |
| 이미 신고한 콘텐츠 재신고 | 운영 정책에 따라 안내 |

#### 내가 접수한 신고 이력

> 회원이 본인이 접수한 신고의 처리 상태를 확인할 수 있다.

**누가**: 본인

**정상 흐름**: 신고 상태(접수 / 검토중 / 처리완료 / 반려)별로 표시.

## 4. 알림 발송 명세

| 트리거 | 수신자 | 본문 (예시) | 카테고리 |
|--------|--------|-----------|---------|
| 신고 처리 결과(수용 또는 반려) | 신고자 본인 | "회원님이 신고하신 내용이 {조치되었습니다/반려되었습니다}." | 신고 |
| 신고 누적·운영자 판단으로 본인 콘텐츠 숨김 | 콘텐츠 작성자 | "회원님의 {게시글/댓글}이(가) 신고에 의해 숨김 처리되었습니다." | 시스템 |
| 운영자가 본인 계정에 제재(정지/차단) 적용 | 본인 | (회원 도메인의 "계정 정지·차단 알림"과 동일 본문) | 시스템 |

**공통 정책**
- 시스템·신고·보안 카테고리는 사용자가 알림 설정에서 끌 수 없다.
- 신고 대상 사용자에게는 누가 신고했는지 노출하지 않는다.

## 5. 정책·규칙

| 항목 | 값 |
|------|------|
| 차단의 즉시 효과 | 차단은 모든 화면(피드·검색·알림·마이페이지)에 동시에 영향 |
| 신고 누적 자동 숨김 임계 | 운영 정책으로 정의 (예: N회 이상 누적 시 자동 숨김) |
| 재가입 차단 유지 여부 | 차단 대상이 탈퇴 후 재가입했을 때 차단 유지 여부 운영 정책으로 정의 |
| 본인 콘텐츠 자가 신고 | 금지 |

## 6. 도메인 공통 예외

- 차단 / 신고로 인한 노출 변경은 여러 화면에 동시에 영향을 준다 — 한 화면만 보지 말고 교차 검증 필요.
