# 11. 공통 정책·요구사항

> 특정 도메인에 속하지 않지만 모든 기능에 영향을 주는 공통 동작·정책. 각 도메인의 기능 명세와 함께 검토한다.

## 1. 도메인 정의

본 장은 단일 도메인에 귀속되지 않는 횡단(cross-cutting) 요구사항을 다룬다. 인증·외부 연동·정책·보안 등 모든 기능이 공통으로 따르는 동작과 약속을 정의한다.

> 본 장의 항목은 사용자 기능이 아니라 **정책·요구사항**이므로, 도메인 기능 명세와 달리 "사용자 가치 / 정상 흐름" 형식이 아닌 **요구사항 / 확인 포인트** 형식을 사용한다.

## 2. 공통 요구사항

### 2.1 외부 연동

#### 소셜 로그인 동작

> 4대 외부 사업자(Google / Kakao / Naver / Apple)와의 로그인 연동이 일관되게 동작한다. 상세 흐름은 회원 도메인의 "소셜 로그인" 참조.

**요구사항**

| 항목 | 내용 |
|------|------|
| 일관된 결과 | 동일 사용자에 대해 어느 경로로 로그인해도 같은 회원으로 매핑 |
| 신규/기존 분기 | 제공자별로 동일하게 동작 |
| 인증 정보 오류 | 일관된 에러 메시지 |

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 외부 사업자 일시 장애 | 사용자 친화적 안내 |
| 잘못된/만료된 인증 정보 전달 | 일관된 에러 메시지 |

#### 이미지 업로드 동작

> 학생증·프로필 이미지 등 사용자가 사진을 올리는 모든 경우에 일관된 흐름과 실패 처리를 따른다.

**사용처**: 학생증 제출, 프로필 이미지 변경

**요구사항**
1. 사용자가 사진을 선택하면 업로드 진행이 표시됨
2. 완료 시 다음 단계로 자동 진행
3. 도중 실패 시 명확한 안내와 재시도 옵션
4. 업로드는 성공했지만 마지막 통보가 실패한 경우 동일 화면에서 재시도 가능
5. 업로드 화면에 오래 머문 뒤 다시 시도해도 새 업로드가 정상 처리

**정책**: 형식·용량 상한은 운영 정책으로 정의.

#### 푸시 알림 등록·해제

> 회원 디바이스의 알림 수신 등록·해제가 자동으로 관리된다.

**요구사항**

| 항목 | 내용 |
|------|------|
| 권한 허용 시 | 디바이스가 자동으로 알림 수신 등록 |
| 알림 키 갱신 | 자동 재등록 |
| 로그아웃 시 | 알림 등록 자동 해제 |

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 권한 거부 디바이스 | 어떤 알림도 도달하지 않아야 함 |
| 같은 계정 다중 기기 로그인 | 운영 정책으로 정의 |
| 다른 계정으로 재로그인 | 이전 계정의 알림이 더 이상 도착하지 않아야 함 |

#### 알림 카테고리 정의

> 회원이 마이페이지의 알림 설정에서 ON/OFF할 수 있는 단위. 도메인별 알림 발송 명세의 "카테고리" 컬럼이 본 정의를 참조한다.

**카테고리 매트릭스**

| 카테고리 | 설명 | 예시 알림 | ON/OFF |
|---------|------|-----------|--------|
| 시스템 | 계정 상태·필수 안내 | 학생증 승인/거절, 정지·차단, 탈퇴 완료, 콘텐츠 숨김/계정 제재 | **불가**(항상 수신) |
| 보안 | 보안 관련 통지 | 비밀번호 변경 완료 | **불가**(항상 수신) |
| 신고 | 신고 처리 결과 | 신고 처리 결과 통지 | **불가**(항상 수신) |
| 공지 | 운영자 공지 | 운영 공지(전체 또는 학교별) | 가능 |
| 좋아요 | 본인 콘텐츠에 받은 좋아요 | 게시글·댓글·투표·다짐의 좋아요 알림 | 가능 |
| 댓글 | 본인 콘텐츠에 달린 댓글·답글 | 게시글·투표·다짐의 댓글, 댓글에 달린 답글 | 가능 |
| 활동 | 본인 콘텐츠에서 발생한 활동(투표 참여·마감 등) | 투표 새 참여자, 투표 마감, 활동 점수 마일스톤 | 가능 |
| 일정 | 일정 사전 리마인더 | 일정 시작 N분 전 | 가능 |
| 행사 | 본인 학교 행사 안내 | 학교 행사 등록 | 가능 |
| D-Day | D-Day 임박 알림 | D-Day 임박(D-N) | 가능 |
| 배지 | 새 배지 획득 | 배지 획득 | 가능 |
| 랭킹 | 학교 랭킹 결과 | 학교 랭킹 주간 결과 | 가능 |
| 리마인더 | 출석·다이어리 등 리마인더 | 출석 끊김 위기, 다이어리 작성 리마인더 | 가능 |
| 마케팅 | 이벤트·프로모션 | 회원가입 환영(일부) | **별도 동의** 필요(가입 시 선택) |

**공통 정책**

| 항목 | 정책 |
|------|------|
| 시스템·보안·신고 | 사용자가 끌 수 없음(필수 통지) |
| 마케팅 | 마케팅 동의 회원에게만 발송. 동의 철회 시 즉시 발송 중단 |
| OS 알림 권한 거부 | 카테고리 설정과 무관하게 어떤 푸시도 도달하지 않음 |
| 야간 발송 차단 | 운영팀이 결정. 시스템·보안·신고는 야간에도 발송 |
| 묶음 발송(batch) | 동일 트리거가 단시간에 다수 발생 시 묶음 발송 |
| 인앱 알림 동시 적재 | 모든 푸시는 인앱 알림 목록에 동시 적재. 클릭 시 해당 콘텐츠로 이동 |

### 2.2 정책·약관

#### 약관 동의 이력

> 가입 시 약관 동의 항목별로 동의 시각이 기록되며, 약관 시행일 변경 시 재동의가 필요하다.

**요구사항**: 가입 시 서비스 약관·개인정보 처리방침·마케팅 동의(선택)·만 14세 이상 확인 등 항목별로 동의 시각이 기록된다.

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 약관 시행일 변경 | 기존 회원에게 재동의 요구 |
| 마케팅 미동의 회원 | 마케팅성 알림 미수신 |

#### 외부 정책 페이지

> 이용약관·개인정보 처리방침 등은 외부 웹페이지로 제공된다.

**연결 링크**

| 항목 | 링크 |
|------|------|
| 이용약관 | `https://www.claspeek.com/terms/` |
| 개인정보 처리방침 | `https://www.claspeek.com/privacy/` |
| 고객지원 | `https://www.claspeek.com/support/` |
| 계정 삭제 안내 | `https://www.claspeek.com/account-deletion/` |

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 외부 브라우저 진입 | 앱 안의 웹뷰가 아니어야 함 |
| 인터넷 끊김 | 진입 실패 안내 |
| 시행일 일치 | 페이지 시행일과 앱 표기 일치 |

### 2.3 데이터·콘텐츠 정합성

#### 삭제된 콘텐츠 노출 정책

> 삭제된 콘텐츠는 모든 사용자 시점 화면에서 더 이상 노출되지 않는다.

**요구사항**: 게시글·다짐·투표·일정·다이어리 등이 삭제된 후에는 피드·검색·상세 등 어떤 화면에서도 노출되지 않는다.

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 삭제 직후 검색 결과 | 즉시 제외 |
| 차단 후 해제했을 때 과거 콘텐츠 노출 | 정책 일관성 유지 |

#### 부적절한 단어 차단

> 사용자 입력에 부적절한 단어가 포함되면 차단한다.

**적용 범위**: 게시글·댓글·투표 옵션·닉네임 등 모든 사용자 입력.

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 단어 변형(공백·특수문자) 우회 | 차단 정책 운영 정책으로 정의 |
| 차단 시 메시지 | 사용자에게 명확히 안내(어떤 단어인지는 미공개 가능) |

### 2.4 보안

#### 보안 기본

> 모든 통신과 민감 정보 저장은 보안 표준을 따른다.

**요구사항**

| 항목 | 내용 |
|------|------|
| 통신 | 모든 통신은 보안 통신(HTTPS) |
| 로그인 정보 저장 | 디바이스의 안전한 저장소에만 보관 |
| 민감 화면 보호 | 학생증 등 민감 화면 스크린샷 차단 정책(운영 정책) |

**확인 포인트**: 디버그용 빌드와 정식 빌드의 보안 설정 차이.

### 2.5 시스템·플랫폼

#### 앱 강제 업데이트 안내

> 너무 오래된 앱 버전 사용을 차단하기 위해 강제 업데이트를 안내한다.

**요구사항**

| 케이스 | 동작 |
|--------|------|
| 강제 업데이트 필요 | 스토어 이동 안내, 다른 화면 진입 차단 |
| 권장 업데이트 | 안내만 표시, 사용자가 닫고 사용 가능 |
| 통과 | 정상 진입 |

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 강제 업데이트 안내 | 다른 화면을 가려야 함 |
| iOS/Android 각각 | 정상 표시 + 스토어로 정확히 연결 |

#### 시간대·언어

> 시간대 변경에 따른 시간 의존 기능 안정성, 다국어 지원.

**요구사항**: 디바이스 시간대를 변경해도 서버 시각 기준 기능(투표 마감·D-Day·출석)은 흔들리지 않는다. 다국어는 한국어 우선.

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 디바이스 시간대 변경 | 일정·D-Day·출석 동작이 의도대로 |
| 한국어 외 시스템 언어 | 텍스트 깨짐 없어야 함 |

#### 접근성·기본 UX

> 모든 화면에서 따라야 하는 기본 UX 가이드라인.

**요구사항**

| 항목 | 기준 |
|------|------|
| SafeArea | 화면 가장자리(노치/홈 인디케이터 영역)에 텍스트·버튼 가리지 않음 |
| 키보드 닫기 | 입력 화면에서 키보드 외부 탭 시 키보드 닫힘 |
| 큰 글자/다크모드 | 시스템 설정 지원 여부 확인 |

### 2.6 운영·안정성

#### 짧은 시간 반복 요청 제한

> 좋아요·북마크 등 빠른 연타 시 일부 요청이 차단될 수 있다.

**요구사항**: 차단되더라도 화면이 흔들리거나 비정상 상태로 빠지지 않아야 한다.

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 차단 발생 | UI가 흔들리지 않아야 함 |
| QA 자동화 스크립트 | 의도치 않게 차단되지 않도록 사전 안내 |

#### 오프라인·네트워크 변화

> 인터넷 단절·전환 시 사용자 경험을 일관되게 유지한다.

**요구사항**

| 항목 | 내용 |
|------|------|
| 인터넷 단절 | 사용자에게 명확한 표시 |
| 작성 중 끊김 | 재연결 후 자동 재시도 또는 명시적 재시도 |

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 비행기 모드 ON/OFF | 각 화면 정상 복구 |
| 4G ↔ Wi-Fi 전환 | 진행 중 요청 안정성 |

#### 광고 노출

> 지정된 위치에 광고가 표시되고 클릭 시 정상 이동한다.

**요구사항**

| 항목 | 내용 |
|------|------|
| 노출 위치 | 위치/섹션별로 적절한 광고 표시 |
| 노출 추적 | 같은 광고가 들어왔다 나갔다 할 때 중복 추적되지 않음 |
| 클릭 이동 | 외부 링크 또는 앱 내 화면으로 정확히 이동 |

#### 공통 에러 표시

> 모든 에러는 사용자에게 한국어로 일관되게 표시된다.

**요구사항**: 네트워크/서버 오류는 사용자에게 한국어 메시지로 일관되게 표시.

**확인 포인트**

| 항목 | 결과 |
|------|------|
| 클라이언트 잘못된 요청 vs 서버 오류 | 메시지가 적절히 구분 |
| 알 수 없는 에러 | 일반 안내 + 재시도 옵션 |
| 정식 빌드 | 디버그 정보(개인정보·로그인 정보) 화면 미노출 |
