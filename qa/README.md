## 3. 기능 명세 작성 양식

각 기능은 다음 양식을 따른다. **한 줄 요약 → 정상 흐름(번호 단계) → 표 형식의 조건·예외** 순으로 정리한다.

```markdown
#### 기능 이름

> 한 줄로 사용자 가치를 설명한다.

**누가**: 비회원 / 정상 회원 / 본인 / ...

**정상 흐름**
1. 첫 단계
2. 둘째 단계
3. 셋째 단계

**입력 조건**

| 항목 | 조건 |
|------|------|
| ... | ... |

**예외 처리**

| 상황 | 결과 |
|------|------|
| ... | ... |
```

- **한 줄 요약**(`>` 인용문): "누가 ~할 수 있다" 형태로 사용자 가치를 명시.
- **누가**: 이 기능을 사용할 수 있는 회원 상태(비회원·정상 회원·본인 등).
- **정상 흐름**: 모든 것이 정상일 때의 사용자 흐름을 번호로 짧게.
- **입력 조건**(필요 시): 사용자가 입력하는 값이나 충족해야 하는 조건을 표로.
- **예외 처리**(필요 시): "어떤 상황 → 어떤 결과(메시지/제한)"를 표로.
- 단순한 기능은 표 없이 한 줄로 정리해도 된다.

## 부록 B. 사용자 권한 한눈에 보기

- **로그인 없이 사용 가능**: 앱 소개, 로그인, 회원가입(다단계), 정책 페이지 외부 링크.
- **로그인 필수**: 위 항목을 제외한 거의 모든 기능(홈, 커뮤니티, 투표, 다짐, 일정, 다이어리, 검색, 알림, 마이페이지 등).
- **본인만**: 본인이 작성한 콘텐츠의 수정/삭제, 본인 다이어리, 본인 프로필·계정 정보 변경.
- **관리자 전용**: 관리자 기능은 본 명세 범위 외이며, 별도 안내가 필요하면 운영자 측에 요청.
- **짧은 시간 반복 요청 제한**: 좋아요/북마크 등 빠른 연타 시 일부 요청이 거절될 수 있다.
- **자동 로그인 화면 이동**: 로그인이 필요한 화면에 미로그인으로 진입하면 자동으로 로그인 화면으로 이동.
